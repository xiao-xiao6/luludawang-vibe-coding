## ✨ 一句话介绍

**「图片收藏夹」常见的痛点是：换个浏览器、清个缓存、重装个系统，攒了几年的图就没了；而全塞进浏览器存储，C 盘又会悄悄膨胀到几个 G。**

好图收纳屋的做法是把这两件事拆开：

| 东西 | 住在哪 | 说明 |
| --- | --- | --- |
| **原图**（像素本体） | 📁 你指定的硬盘文件夹（`D:\`、`E:\`、移动硬盘都行） | 通过 File System Access API 读写，图库再大也不占 C 盘 |
| **索引**（名字 / 标签 / 评分 / 合集 / 备注） | 🗄️ 浏览器 IndexedDB + 文件夹里的 `_meta.json` | 体积只有几 MB，删了也不怕 |

于是：**清缓存不怕、换浏览器不怕、重装系统不怕** —— 点一次「🔄 扫描文件夹恢复」，整个图库连标签一起回来。

## 🚀 快速开始

### 方式一：直接用

1. 下载本仓库，找到 `部署版/index.html`
2. 用 **Chrome** 或 **Edge** 打开（双击即可，不需要服务器）
3. 进「🗃️ 数据管理」→「📁 选择图库文件夹」，指一个你喜欢的盘
4. 回到「🎀 相册」，拖图、粘贴、上传，开始收藏 ✿

### 方式二：部署到 GitHub Pages

把 `部署版/` 里的 `index.html` 与 `brand_160.png` 一起放到仓库根目录，开启 Pages 即可。
（`index.html` 里的分享卡片元信息已按 `https://xiao-xiao6.github.io/luludawang-vibe-coding/` 填好，换成自己的地址就行。）

> 💡 **纯静态、无后端、无账号、无追踪**。所有数据只在你自己的电脑上，图片不会被上传到任何地方。

#### 图库文件夹长这样

```

└── _meta.json         # 元数据档案：名字 / 标签 / 评分 / 合集 / 备注
```

## 🔬 技术实现亮点

### 1️⃣ 零依赖、单文件

没有 npm、没有打包器、没有 CDN、没有框架。一个 `.html` 文件就是全部产品 —— 便于分发、便于备份、断网也能用、永远不会因为第三方库挂掉而失效。

### 2️⃣ 原图与索引分离的存储架构

```
上传 → 原图写入文件夹 images/  →  IndexedDB 只存元数据（不含像素）
     → _meta.json 同步落盘      →  卡片滚动到附近时才按需读盘
```

- `metaOnly()` 会把已经落盘的记录里的像素字段清掉，**C 盘几乎不占空间**
- 缩略图用 `IntersectionObserver` 按需读盘，`IMG_CACHE` 最多留 100 张，超了回收最早的
- 支持旧版「镜像备份」数据的平滑迁移（`legacyDataUrl()` 兜底），不会丢图
- 没有文件夹权限时**降级但不丢数据**：先把图安全存在浏览器里，同时提示重新授权

### 3️⃣ 自研 GIF89a 编码器

不依赖任何库，从零实现规范里的那套：

- `medianCutPalette()` —— 中位切分算法挑出最合适的 256 色
- `quantizeFrame()` —— 15 位颜色缓存加速的像素 → 调色板索引映射
- `lzwEncode()` —— GIF 规范里的变长 LZW 压缩
- `buildGif()` —— 拼成完整 GIF89a 字节流
- 还有 Bayer 有序抖动矩阵，渐变更平滑

### 4️⃣ 自研 MP4 容器封装

`buildMp4Bytes()` 手写 MP4 盒子结构：`ftyp` + `mdat` + `moov`（含 `mvhd` / `tkhd` / `mdhd` / `hdlr` / `avc1` / `avcC` / `stbl` 系列），配合 WebCodecs 拿到的 H.264 编码帧，生成标准可播放的 MP4。没有 WebCodecs 时回退 `MediaRecorder`。

### 5️⃣ 性能与稳定性

- **分块渲染**：`GALLERY_CHUNK = 80`，滚到「再看 N 张」附近自动续批
- **rAF 合并重排**：`onViewportChange()` 把旋转 / 地址栏伸缩 / 拖窗口合并成一帧一次
- **防抖**：搜索 200ms；`_meta.json` 写入防抖 + 页面隐藏 / 关闭前强制落盘
- **事件委托**：id 与参数走 `data-*` 属性，不拼进 JS 字符串，杜绝引号注入
- **占位防抽动**：卡片用记录的宽高先算好占位比例，原图晚到版面也不跳
- **写失败绝不静默**：配额满 / 无痕 / 授权过期都会明确报错，不会假报「已保存」
- **全站工程兜底**：`hardenButtons()` 给几百个按钮补 `type="button"`；站内 `confirm` / `prompt` 全部替换成同风格的弹窗

### 6️⃣ 安全与隐私

- **零后端**：没有服务器、没有账号、没有埋点、没有遥测
- **图片不外传**：只有你主动用「图片转直链」时才会传到你自己选的图床
- **API Key 只存本机**：imgbb Key 存在你浏览器的 `localStorage`，不会发到别处
- **删除可逆**：所有删除先进 `_trash`，确认清空才真删

## ❓ 常见问题

**Q：一定要用 Chrome / Edge 吗？**
想要「原图住文件夹、C 盘不膨胀」这个核心体验，是的。其他浏览器仍可正常收藏浏览，只是原图会留在浏览器存储里。

**Q：重启浏览器后说没权限了？**
这是浏览器安全设计，不是 bug。点一次「🔓 重新授权」即可。

**Q：不小心删了图怎么办？**
先看气泡里的「撤销」（7 秒内）。超时了就去「🗃️ 数据管理 → 🗑️ 回收站」，原图一直在 `_trash` 里等你。

**Q：换电脑 / 重装系统后图库还在吗？**
在。原图就在你的文件夹里。新环境选一次同一个文件夹 →「🔄 扫描文件夹恢复」，标签评分也会按 `_meta.json` 还原。

**Q：会占多少 C 盘？**
索引只有几 MB。原图全在你指定的盘上。

**Q：图片会上传到网上吗？**
不会。除非你主动使用「图片转直链」。
