📁 图库文件夹（原图主库）

原图只存在你指定的盘（D:\ / E:\ / 移动硬盘都行），浏览器里只留名字 / 标签 / 评分这些「文字索引」。图库再大，C 盘也只占几 MB。缓存被清空也不怕，扫描文件夹就能把整个图库恢复回来。

文件夹里会有 images（原图）和 _meta.json（名字 / 标签 / 评分 / 合集）。删除不会硬删：原图会先进 _trash，在下面的「🗑️ 回收站」里可以一键恢复或彻底清空。⚠️ 浏览器重启后授权会过期（安全设计，原图主库唯一的代价）：点一次「🔓 重新授权」，就能继续看图与写入。

🗑️ 回收站（_trash）

删除图片时原图不会硬删，而是搬进图库文件夹里的 _trash。这里可以把它们整批挪回 images，也可以彻底清空释放磁盘 —— 「手滑也还有救」不再是空话。

📚 合集管理

用「合集」把图片分成一组组，相当于好几本相册。也可以直接在首页把「图片卡片」拖到某个合集上，一拖就归类～

🏷️ 标签管理

重命名或删除标签会同步更新到所有图片上。首页的标签条里，每个标签都能直接拖到某张图片上，松手就打好标签啦。

批量操作

🔗 图片转直链

选几张图片 → 上传到公开图床 → 拿到 https:// 开头的直链，可以直接贴到论坛、文档、聊天窗口里。
免注册的图床是临时的（1～72 小时）；想长期保留，填一个自己的 imgbb Key 就好。

🎞️ 多图合成 GIF

把好几张图变成一张会动的 GIF：图片之间会加上连续插值的平滑过渡（叠化 / 白闪 / 擦除 / 滑动 / 缩放），不会"啪"地一下跳过去。顺序就是下面缩略图的顺序。
